🧩 Direção Criativa — dois prompts que trabalham juntos

O Prompt 1 determina a aparência e a referência. O Prompt 2 define o que acontece: letra, história, ações ou cenas aleatórias. As descrições e animações combinam os dois.

🎨 Prompt 1 — Estilo visual

A imagem orienta a aparência. Para gerar no Gemini/Flow, anexe também a mesma foto de referência.

Estilo + referência + cores entram na geração visual; o Prompt 2 continua só para história e ações.

🎬 Prompt 2 — Conteúdo e ações

Prontas: cole todas as cenas numeradas, cada número numa linha. Aleatórias: descreva o clima e o assunto da música; as ações terão causas físicas naturais.

Ao colar cenas numeradas, o programa identificará automaticamente cada cena.

Cenas prontas: cole 01. ... / 02. ... / 03. ... em linhas separadas. Cenas aleatórias: escreva o clima, a letra ou as ações.

🔒 Ficha do estilo gêmeo da referência

Correção V7: estilo visual fixo + assunto variável por cena. A referência NÃO deve ser copiada como conteúdo. No modo Aleatório, cada cena pode mostrar um assunto diferente.

A paleta é extraída dos pixels da imagem enviada. O prompt gêmeo descreve somente materiais, cores e iluminação, sem copiar os personagens da referência. A análise visual por IA ainda não está integrada; revise o resultado antes de bloquear.

Se preencher o campo de acréscimo, o texto será adicionado ao final do Prompt Gêmeo. Se deixar vazio, o botão aplicará as alterações já feitas no Prompt Gêmeo. As imagens e descrições não serão alteradas.

V12: a prévia Gemini e os prompts Flow automáticos acompanham as alterações do estilo; prompts Flow escritos manualmente são preservados. O bloqueio protege o texto contra edições acidentais; não garante fidelidade absoluta de uma IA externa. Na geração, envie também a imagem original como referência visual.

2. Gerar e revisar cenas

V12 — Fluxo gratuito: toque em Copiar IMAGEM, depois Abrir Gemini. Cole o prompt no Gemini e gere a imagem. Salve a imagem no celular, volte aqui e toque em Importar imagem na mesma cena. O Gemini não recebe o prompt automaticamente e nenhuma API paga é utilizada.

Correção V9: o botão de IMAGEM copia somente o prompt Gemini da cena aberta; o botão de ANIMAÇÃO copia somente o prompt Flow. Confira o texto em “Ver exatamente o prompt de IMAGEM”. Para um trem, o texto precisa dizer trem, nunca caminhão. No estilo Barroso, a massinha continua. Com um prompt livre, o estilo escolhido tem prioridade.
